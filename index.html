CreuzeBeck-Rclone

Aplicativo de uso pessoal para copiar arquivos autorizados de uma pasta local para o Google Drive.

A ferramenta utiliza Rclone e a API do Google Drive para realizar transferências periódicas, mediante autorização do titular da conta.

O aplicativo não oferece acesso público aos arquivos sincronizados.
