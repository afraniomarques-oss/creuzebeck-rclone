Política de Privacidade

O CreuzeBeck-Rclone é uma integração de uso pessoal destinada a copiar arquivos autorizados de um computador para o Google Drive.

Dados acessados

O aplicativo utiliza a API do Google Drive, mediante autorização do titular da conta, para consultar pastas, criar arquivos e atualizar arquivos existentes.

Uso e armazenamento

Os arquivos são transferidos diretamente pelo Rclone para a conta Google autorizada. Credenciais OAuth são armazenadas localmente na configuração do Rclone.

Compartilhamento

O aplicativo não publica os arquivos transferidos e não vende dados pessoais. O Google processa os dados necessários à prestação do serviço Google Drive.

Revogação de acesso

O titular pode revogar a autorização nas configurações de segurança da conta Google.
